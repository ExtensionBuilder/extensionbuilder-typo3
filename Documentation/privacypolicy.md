# Privacy and Code Generation

To generate your extension, the project, configuration, and extension data required for code generation is transmitted to the code generator.

The transmitted data is processed exclusively for the purpose of generating your extension.

## Storage and Deletion

The data transmitted for code generation is stored temporarily and **automatically deleted after no more than 48 hours**.

## Personal Data

Any personal data contained in the transmitted information is not evaluated or used for analytics, advertising, or profiling purposes and is not disclosed to third parties.

Please do not transmit passwords, credentials, API keys, or other confidential information unless they are strictly required for code generation.

## Server Location

The data is processed and stored on servers operated by **Hetzner in Germany**.

No data is transferred to third countries outside the European Union (EU) or the European Economic Area (EEA) as part of the code generation process.

## Security

Communication with the code generator takes place via an encrypted HTTPS connection.

By starting the code generation process, the data required to generate your extension is transmitted to the code generator and processed in accordance with this privacy notice.
